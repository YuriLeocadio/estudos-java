# 🥷 Maratona Java - DevDojo

Repositório criado para armazenar todo o progresso, códigos de exemplo e exercícios práticos desenvolvidos durante o curso **Maratona Java (Virado no Jiraya)** ministrado pelo William Suane do DevDojo.

## 🛠️ Tecnologias e Ferramentas Utilizadas

*   **Linguagem:** Java (JDK 25)
*   **IDE:** IntelliJ IDEA
*   **Paradigma principal:** Orientação a Objetos (POO)

## 📌 Conteúdos Estudados

* 🟩 **Configuração de Ambiente** (Instalação do JDK e IDE)
* 🟩 **Sintaxe Básica** do Java e Estruturas Condicionais
* 🟩 Laços de Repetição e Arrays
* 🟩 **Orientação a Objetos** (Classes, Métodos, Encapsulamento, Construtores,
  Static, Associação, Herança, Modificador Final, Enumeração, Classes
  Abstratas, Interfaces, Polimorfismo)
* 🟩 Tratamento de Exceções
* ⬜ Classes Utilitárias (Wrappers, Strings, Data/Hora, Regex, IO/NIO)
* ⬜ Coleções (Lists, Maps, Sets, Generics)
* ⬜ Lambdas, Streams e Programação Funcional
* ⬜ Threads e Concorrência
* ⬜ Padrões de Projeto
* ⬜ JDBC e Persistência
